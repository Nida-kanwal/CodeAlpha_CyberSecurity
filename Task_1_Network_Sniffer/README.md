# CodeAlpha Task 1 - Basic Network Sniffer

## 📌 Project Overview

This project is developed as part of the CodeAlpha Cyber Security Internship.

The objective of this task is to build a basic network packet sniffer using Python and Scapy. The program captures network packets in real time and displays important information about network traffic.

## 🎯 Objectives

- Capture network packets continuously.
- Analyze packet structure and network communication.
- Identify different network protocols.
- Display useful packet information.

## 🛠️ Technologies Used

- Python 3
- Scapy Library
- Kali Linux / Linux Environment

## ✨ Features

The Network Sniffer can display:

- Source IP Address
- Destination IP Address
- Protocol Type:
  - TCP
  - UDP
  - ICMP
- Packet Length
- Payload Data (if available)
- Continuous packet capture
