# CodeAlpha Task 2 - Phishing Awareness Training

## Project Overview

This project is developed as part of the CodeAlpha Cyber Security Internship.

The purpose of this task is to create a phishing awareness training module that educates users about phishing attacks, fake websites, social engineering techniques, and methods to stay protected from cyber threats.

The presentation explains how attackers use fake emails, messages, and websites to trick users and steal sensitive information.

## Objectives

- Understand phishing attacks and their impact.
- Learn how to identify phishing emails and fake websites.
- Understand social engineering techniques used by attackers.
- Provide cybersecurity awareness and prevention methods.
- Improve user knowledge through examples and quizzes.

## Topics Covered

The phishing awareness training covers:

- Introduction to phishing attacks
- Types of phishing:
  - Email Phishing
  - Spear Phishing
  - Smishing
  - Vishing

- Identification of phishing emails:
  - Suspicious sender addresses
  - Unknown links
  - Fake attachments
  - Urgent requests
  - Requests for sensitive information

- Identification of fake websites:
  - Checking website URLs
  - HTTPS verification
  - Domain spelling
  - Avoiding suspicious login pages

- Social engineering techniques:
  - Fear
  - Urgency
  - Trust manipulation
  - Curiosity
  - Fake authority

- Real-world phishing examples

- Prevention and safety practices:
  - Avoid unknown links
  - Verify sender identity
  - Use strong passwords
  - Enable Multi-Factor Authentication
  - Report suspicious messages

The presentation includes quiz questions to test users' understanding of phishing attacks and safe online practices.
